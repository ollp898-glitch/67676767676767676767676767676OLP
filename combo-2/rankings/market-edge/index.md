# Combo 2.0 — рейтинг исходов

[Главная Combo 2.0](../../README.md) · [JSON-индекс](index.json)

Снимок: 2026-10-10T17:28:54.552Z. ID: 8cc3e80f01e941355d3e.

В рейтинге: **2411** исходов. Без подтверждённой fair probability: **13317**. Киберспорт исключён.

Сортировка: **market_edge_pp по убыванию** = Median БК − вероятность Polymarket. Показатель «Polymarket vs market median» имеет обратный знак.

**Median БК** — медиана fair probability, рассчитанной отдельно для каждой БК: (1 / коэффициент исхода) / сумма(1 / коэффициенты всех взаимоисключающих исходов этого рынка). Используются только полные активные рынки той же БК, события, периода и линии. Неполные, неоднозначные и пересекающиеся рынки не входят в медиану. Минимум для рейтинга — одна БК с полным рынком. Betfair учитывается наравне с остальными.

В скобках у каждого коэффициента показана fair probability; «—» означает, что её корректно рассчитать нельзя. Сырые коэффициенты сохранены.
